# تاریخچه تغییرات نسخه ۲.۸.۰ — «شخصی‌سازی کامل ظاهر»

> نسخه مبنا: ۲.۷.۰ | تاریخ انتشار: ۱۴۰۴/۰۶/۲۸
> موضوع این نسخه: صفر کردن تضاد ظاهری افزونه با قالب سایت — شما صاحب سبک هستید، نه افزونه!

---

## 🎨 ویژگی جدید اصلی: پنل «ظاهر و شخصی‌سازی»

از این نسخه، همه استایل‌ها، فونت‌ها و کدهای نمایشی افزونه قابل کنترل و حذف هستند.
مسیر: **پیشخوان وردپرس → ووکامرس → پیش‌بینی هوشمند خرید → بخش «🎨 ظاهر و شخصی‌سازی»**

### ۱) کلید اصلی خاموش/روشن استایل‌ها
- با یک تیک می‌توانید **بارگذاری کل CSS افزونه را در سایت قطع کنید**.
- در این حالت ویجت‌ها فقط HTML معنایی دارند و دقیقاً با استایل خود قالب شما رندر می‌شوند.
- عملکرد (AJAX افزودن به سبد و…) سر جایش می‌ماند؛ فقط ظاهر به قالب واگذار می‌شود.

### ۲) سه پیش‌تنظیم نمایشی
| پیش‌تنظیم | رفتار |
|---|---|
| **۱. طراحی پیش‌فرض** | همان شکل شناخته‌شده افزونه (کارت‌های رنگی اختصاصی) |
| **۲. مینیمال** | تخت، بی‌سایه، بی‌گرادیان — فقط رنگ‌های پالت شما |
| **۳. هماهنگ با قالب (پیشنهادی)** | پس‌زمینه، رنگ متن، قیمت‌ها و سایه از قالب ارث‌بری می‌شود؛ فقط رنگ تاکیدی مدیر باقی می‌ماند |

### ۳) خاموش/روشن مستقل هر ویجت (حذف کدهای نمایشی هر بخش)
- باکس پکیج هوشمند صفحه محصول
- پیشنهادات مکمل صفحه سبد خرید
- آپسل یک‌کلیکی صفحه تشکر
- نوار پیشرفت ارسال رایگان (با کالاهای پرکننده)
- ویجت پیش‌بینی خرید بعدی در حساب کاربری
- بنر پیشنهاد هوشمند بالای نتایج جستجو (کلید مستقل از تزریق در نتایج)
- (کلید مودال خروج طبق قبل در تنظیمات عمومی است)
- شورت‌کدها مستقل از این کلیدها هستند؛ قرار دادن شورت‌کد در صفحه = انتخاب صریح شما.

### ۴) پالت رنگ ویجت‌ها
۶ انتخابگر رنگ با اعمال فوری: رنگ اصلی، متن روی رنگ اصلی، پس‌زمینه بج‌ها، متن بج‌ها، پس‌زمینه کارت‌ها، حاشیه کارت‌ها. رنگ hover دکمه‌ها به‌صورت خودکار از رنگ اصلی محاسبه و تیره‌تر می‌شود.

### ۵) تایپوگرافی و فرم
- **گردی گوشه‌ها (۰ تا ۳۰px)** — برای قالب‌های زاویه‌دار عدد صفر بگذارید.
- **اندازه پایه متن (۱۱ تا ۱۸px)** — کل تایپوگرافی ویجت‌ها نسبت به آن مقیاس می‌شود.
- **تعهد فونت:** این افزونه در هیچ حالتی font-family تزریق نمی‌کند؛ فونت همیشه از قالب شما ارث‌بری می‌شود.
- **جهت چیدمان:** تحمیل RTL قابل خاموش‌کردن است (برای قالب‌های چپ‌چین/دوزبانه).
- **برچسب‌های آماری:** همه درصدهای اطمینان/همبستگی با یک تیک مخفی می‌شوند.
- **ایموجی‌ها:** همه ایموجی‌های متن ویجت‌ها (⚡ 🎉 🛍️ …) قابل حذف‌اند.

### ۶) CSS سفارشی
- باکس CSS سفارشی برای مدیر فروشگاه (فقط CSS خالص؛ تگ HTML خودکار حذف می‌شود؛ حداکثر ۲۰ هزار کاراکتر).
- حتی در حالت «بدون استایل افزونه» هم منتشر می‌شود تا بتوانید ویجت‌ها را دستی به قالب وصل کنید.
- فهرست کامل سلکتورها و متغیرها در پنل (بخش بازشو زیر باکس) در دسترس است.

### ۷) پیش‌نمایش زنده 👁️
کارت نمونه در خود پنل با **تنظیمات فعلی فرم** رندر می‌شود؛ با تغییر هر رنگ/عدد/پیش‌تنظیم، بلافاصله (قبل از ذخیره) نتیجه را می‌بینید.

## 🛠️ برای توسعه‌دهندگان قالب

- فیلتر `fws_styles_enabled` — قطع CSS از سمت قالب
- فیلتر `fws_component_enabled` — کنترل فعال/غیرفعال هر ویجت از سمت قالب/افزونه دیگر
- فیلتر `fws_widget_html` — بازنویسی کامل HTML هر ویجت
- فیلتر `fws_custom_css` / `fws_style_variables` — کنترل CSS سفارشی و متغیرها
- استایل‌شیت ۱۰۰٪ بر پایه متغیرهای CSS است: `--fws-accent`, `--fws-box-bg`, `--fws-radius`, `--fws-font-size`, `--fws-badge-bg`, `--fws-text-main`, `--fws-price-color` و…

## 🐞 رفع اشکالات ظاهری این نسخه

1. **کارت‌های باکس سبد خرید از همیشه بی‌استایل بودند** — کلاس‌های `.fws-cart-grid`, `.fws-cart-item`, `.fws-cart-title` در هیچ نسخه‌ای استایل نداشتند؛ حالا کامل استایل‌دهی شدند (همچنان با متغیرها و قابل شخصی‌سازی).
2. **نام، قیمت و برچسب آیتم‌های پکیج استایل نداشتند** — `.fws-item-name`, `.fws-item-price`, `.fws-item-tag`, `.fws-pricing-breakdown`, `.fws-original-price`, `.fws-discounted-price` استایل‌دهی شدند.
3. حذف استایل inline هاردکد از ویجت حساب کاربری (`color:#1e293b` در تگ h4) → کلاس تمیز با متغیر.
4. متن بج مودال خروج حالا از پالت رنگ پیروی می‌کند (قبلاً قرمز ثابت بود).

## 📋 نکات نصب و سازگاری

- نصب: فایل‌ها را روی نسخه قبلی بازنویسی کنید (تغییر ساختار دیتابیس وجود ندارد).
- تمام تنظیمات قبلی حفظ می‌شود؛ کلیدهای جدید با مقادیر پیش‌فرض امن اضافه می‌شوند (ظاهر فعلی شما تغییر نمی‌کند).
- حذف افزونه: همه تنظیمات ظاهری هم داخل همان آپشن واحد است و با حذف افزونه پاک می‌شود.
- سازگار با PHP 7.4+ و WooCommerce 6+ (اعلان سازگاری HPOS و Cart/Checkout Blocks حفظ شده است).
- اعتبارسنجی: هر ۱۱ فایل PHP با گرامر PHP 8.1 تجزیه موفق شدند؛ هر دو فایل JS از بررسی سینتکس گذشتند.
